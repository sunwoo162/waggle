# AP 캐릭터·계정 도감 검토

범위: 996f405..575bfc4. 별도 읽기 전용 리뷰 한 건으로 학교/일반 사용자 스키마 이전, 캐릭터·이미지 저장, 인증된 앱 도감·수집 API와 관리자 화면을 검토했다. 리뷰어가 관련 15개 검사를 실행해 통과했다. Critical·Important 발견은 없었다.

Minor 한 건: 그림 A 선택 → 그림 제거 → 같은 A를 다시 선택하면 파일 입력의 기존 값 때문에 change가 발생하지 않았다. 실제 브라우저에서 두 미리보기 이미지가 모두 사라진 채 유지되는 것을 재현했다. File 객체를 확보한 뒤 입력 값을 비우도록 수정하고 같은 순서로 재선택했을 때 컬러·회색 미리보기 2개와 빈 파일 입력 값을 확인했다. 낮은 위험의 UI 수정으로 실제 화면 검증을 사용했다. 재리뷰는 수행하지 않았다.

## 검증과 판단

- 실제 React 컴포넌트·HTTP·메모리 DB로 별명·여러 줄 소개·그림 업로드/저장·검색 없음·AP 미등록을 확인했다. 1280px/390px에서 가로 넘침과 저장 후 이미지 로드를 검사했다. 합성 운영자 권한 어댑터를 사용하는 별도 로컬 테스트 서버다.
- 전체 check의 80개 검사·문서·Biome·TypeScript, production build를 통과시켰다. CI는 PR의 정확한 커밋에서 별도로 확인한다.
- 리뷰어가 제외한 실제 DataGSM 인증·운영 DB 이전·학교 무선 연결·OS 관찰·보호 대기열·네이티브 도감 UI는 합성 검사로 증명할 수 없어 후속 범위로 유지했다. 운영 DB를 자동 이전하거나 학교 데이터를 생성하지 않았다.
- 공개 자산은 재인코딩된 캐릭터 그림만 제공한다. 관리 DTO와 설치 장소는 앱 도감에 포함하지 않으며 수집 DB에는 방문 시각이나 기기별 경로가 없다.
