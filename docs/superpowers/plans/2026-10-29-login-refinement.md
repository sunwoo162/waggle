# 로그인 화면 시각 정리 Implementation Plan

> **For agentic workers:** 기존 화면의 작은 스타일 변경이다. 사용자가 디자인을 개발 중 직접 다듬도록 위임했고 이번에도 폰트·크기·레이아웃 수정을 지시했다. 추가 디자인 승인 질문 없이 진행한다.

**Goal:** 과한 소개 영역·영문 장식·반복 설명을 덜고 읽기 편한 운영자 로그인 화면을 만든다.

**Architecture:** 인증 판정·경로·버튼 상태는 유지한다. 서버 페이지의 표현과 auth.css를 정리하고 로컬 Pretendard Variable을 next/font/local로 제공한다.

**Tech Stack:** 기존 Next.js·React·BASE 토큰, Pretendard 1.3.9 (OFL, 원본 파일과 라이선스 포함).

**Spec:** 사용자의 폰트·크기·레이아웃 수정 지시와 docs/design/design-system.md. 중앙 단일 열은 구현자의 시각 판단이다. 기존 넓은 소개/로그인 분할은 반복 설명과 작은 글자가 많아 이번에는 사용하지 않는다.

## 제약과 확인

- BASE 흰색·청록색을 유지하고 그림자·장식 영문·불필요한 배지를 줄인다.
- 제목 28, 본문·버튼 14~16, 보조 설명 12 이상을 사용한다.
- /admin 권한 검사, 로그인·로그아웃·설정 없음·오류 상태를 유지한다.
- 외부 폰트 CDN 요청 없이 빌드·표시한다. 폰트 원본을 수정하지 않는다.
- 표현 변경에는 구현을 복제하는 테스트를 추가하지 않는다. 실제 화면·기존 검사로 확인한다.
