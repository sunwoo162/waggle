# 디자인 시스템

사용자 지정 팔레트와 타입·간격·모션을 적용합니다.

> **채택** 흰 바탕, 청록 #0bb7ae, 핑크 #fc6589, 본문 #233237이 기본입니다. 캐릭터의 개별 색은 유지합니다.


상태: 사용자 제공 BASE 기준을 채택. 의미별 배치와 한글·접근성 보완은 적용 제안.  
원본: [BASE 참고 자료](../../design/references/base-original.md)

## 1. 적용 원칙

- 사용자 지정 색상·타이포 크기·여백·모서리·모션 체계를 공통 기반으로 사용한다.
- UI 기본 바탕은 흰색이고, 청록색은 브랜드와 활성 상태, 핑크색은 주요 강조에 사용한다.
- 학생 앱·Windows 앱·관리자 웹은 같은 토큰을 공유하고 배치만 플랫폼에 맞춘다.
- 도감의 캐릭터 일러스트는 개별 색을 유지할 수 있다. 일반 UI는 공통 팔레트를 따른다.
- 기존 시안의 아이보리·짙은 녹색·종이 그림자 스타일은 현재 기준에서 교체한다. 시안은 화면 구성 참고 자료로 유지한다.
- 일본어 쇼핑몰 문구·로고·상품 가입 흐름을 제품에 가져오지 않는다. 와글의 한국어 화면과 기능에 맞춰 적용한다.

## 3. 의미별 적용 제안

| 목적                       | 배경·표현                                 | 글자                     |
| -------------------------- | ----------------------------------------- | ------------------------ |
| 기본 화면                  | canvas                                    | foreground               |
| 보조 영역                  | gray-50                                   | foreground 또는 gray-600 |
| 경계                       | gray-100~200, 필요 시 border-gray-lighter | 해당 없음                |
| 브랜드·활성 강조           | prime-500                                 | foreground               |
| 작은 글자의 청록 채움 버튼 | prime-800                                 | canvas                   |
| 핑크 강조 버튼             | pink                                      | foreground               |
| 선택·안내 영역             | prime-50~100                              | prime-900                |
| 미수집 도감                | gray-50~100, 회색 캐릭터 실루엣           | gray-600                 |
| 오류 안내                  | red-lighter                               | brown 또는 foreground    |

핑크색은 유지하되 일반 크기의 버튼 라벨은 foreground로 보완한다. 직접 계산한 대비는 흰색/핑크 2.85:1, foreground/핑크 4.65:1이다. 청록 prime-500에는 foreground를 사용하면 5.31:1이며, 흰색 글자용으로는 prime-800을 사용하면 4.69:1이다. 원본에서 측정한 색 토큰과 앱에서 채택하는 의미별 조합을 구분한다.

이 값들은 사용자 제공 색을 바탕으로 계산한 것이며, BASE 원본 웹사이트의 현재 렌더링을 재검증한 결과는 아니다.

## 4. 타이포그래피

크기 체계: 10 / 12 / 14 / 16 / 18 / 20 / 22 / 28.

- 14: 기본 정보·목록·관리자 본문
- 16: 주요 본문·입력·버튼
- 18~22: 구역 제목과 캐릭터 이름
- 28: 큰 페이지 제목
- 12: 보조 설명·날짜
- 10: 제한적인 부가 표기

원본은 TazuganeGothicStdN과 Gilroy를 언급하지만 폰트 파일이 제공된 것은 아니다. 관리자 웹은 Pretendard Variable 1.3.9를 채택해 next/font/local로 제공한다. 원본 WOFF2와 SIL OFL 1.1 라이선스를 저장소에 포함한다. 외부 CDN 없이 빌드·표시하며 Android·Windows의 구체 서체는 해당 앱 구현 시 결정한다.

로그인 화면은 제목 28, 설명·버튼 14~16, 보조 문구 12를 사용한다. 영문 장식 라벨과 큰 소개 영역을 덜고 400px 단일 열에 필요한 동작을 모은다. 작은 화면에서도 본문을 9~10px로 축소하지 않는다.

## 5. 간격·모서리·깊이

원본 간격 토큰: 8 / 16 / 24 / 32 / 40 / 64 / 72 / 80 / 120 / 144. 원본의 단위 없는 수치를 유지하고 플랫폼별 논리 단위로 매핑한다. 큰 여백은 넓은 소개 영역에, 8~32는 앱 안의 밀도에 맞춰 사용한다.

모서리:
- 원본 로그인·헤더 버튼: 0
- 작은 요소: 4
- 카드·패널: 16
- 주요 둥근 CTA: 999

그림자보다 배경·선·간격으로 영역을 구분한다. 원본 홍보 버튼의 60~70 높이와 432 너비를 모든 앱 버튼의 고정 크기로 사용하지 않는다. 모바일 터치 영역과 Windows·관리자 화면의 밀도에 맞춰 크기를 적용한다.

## 6. 컴포넌트 상태

- 일반 로그인 버튼: 흰 바탕·foreground 라벨, hover 시 foreground 바탕·흰 라벨 반전.
- 핑크 CTA: 핑크 바탕에 밝은 8% 덮개로 hover·pressed를 표현한다. 일반 글자의 기본 라벨은 위 대비 보완안을 따른다.
- 키보드 포커스는 플랫폼 기본 포커스 표시를 유지하고 가리지 않는다.
- 입력: 기본·포커스·오류·비활성·처리 중을 구분한다.
- 미수집 캐릭터: 회색 실루엣·가려진 이름.
- 수집 캐릭터: 컬러·재미있는 이름·설정 공개.
- 수집 해금: 운영체제가 등록된 학교 와이파이에 실제 연결 성공한 것을 확인한 뒤 연출한다. 주변 검색 결과만으로 해금하지 않는다.

## 7. 모션

- 기본 hover: 0.2초
- 링크: cubic-bezier(.3, .7, .7, .3)
- 버튼: cubic-bezier(.05, .92, .21, .97)
- 버튼 아이콘: cubic-bezier(.05, .85, .36, .98)
- 드로어: cubic-bezier(.89, .05, .27, 1)
- fade-in: cubic-bezier(.32, 0, .67, 0)
- fade-in-up·진행도: cubic-bezier(0, .55, .45, 1)
- sticky: cubic-bezier(.02, .38, .26, .97)
- 원형 차트: cubic-bezier(.7, 0, .84, 0) / cubic-bezier(.16, 1, .3, 1)

연결 관리 중에는 차분한 상태 갱신을 사용하고, 캐릭터 수집 순간에 짧은 해금 모션을 사용한다. 동작 줄이기 설정에서는 과한 축하·이동 효과를 줄인다.

## 8. 현재 작업 단계

이 문서는 디자인 기준이다. 관리자 웹의 시작·문서·로그인 화면을 구현했고 실제 화면을 보며 다듬고 있다. Android·Windows 화면은 각 앱을 개발하면서 같은 토큰을 적용한다.
