# 전체 화면 명세

Android 17종, Windows 6종, 관리자 웹 11종과 상태 변형입니다.

> **화면 구성안** 기능은 현재 기획을 따르고 시각 기준은 BASE로 통일합니다. 세부 디자인은 개발하면서 다듬습니다.

## M01 시작·자동 로그인 확인

목적: 저장된 로그인과 학교 설정을 확인하는 짧은 시작 화면.

내용: 와글 로고, 대표 캐릭터 하나, '학교의 전파 친구들을 만나러 가는 중' 같은 짧은 문구와 로딩 표시. 기존 로그인이 유효하면 홈으로 이동하고, 처음 사용하면 로그인으로 이동한다. 서버에 잠시 연결되지 않아도 저장된 설정이 있다면 그 상태를 안내하는 변형을 만든다.

## M02 환영·로그인 선택

목적: 처음 사용자가 서비스의 기능을 이해하고 로그인 방식을 고르는 화면.

내용: 대표 캐릭터와 '와이파이는 알아서, 학교생활은 가볍게'라는 제목. '비밀번호 입력 없이 연결을 관리하고, 학교 곳곳의 전파 친구를 모아보세요'라는 설명. 가장 잘 보이는 DataGSM 로그인 버튼, 학교 이메일로 로그인, 개인 초대코드로 로그인 버튼을 배치한다. 첫 설정에는 인터넷 연결이 필요하다는 짧은 안내를 포함한다.

## M03 학교 이메일 입력

목적: 학생 이메일로 인증번호를 요청하는 화면.

내용: 이메일 입력 필드, s로 시작하는 @gsm.hs.kr 주소 안내, '인증번호 받기' 버튼. 입력 형식이 맞지 않는 상태, 발송 중, 잠시 후 재시도가 필요한 상태를 만든다. 학교 이메일의 비밀번호를 요구하지 않는다.

## M04 이메일 인증번호 확인

목적: 이메일로 받은 일회용 인증번호를 확인해 로그인하는 화면.

내용: 발송 대상 이메일, 숫자 인증번호 입력, 남은 유효시간, '인증하고 시작하기', '인증번호 다시 받기', '이메일 변경'. 번호가 틀림·시간 만료·발송 지연·로그인 완료 상태를 포함한다. 인증번호 길이와 시간은 디자인용 예시로 표시한다.

## M05 개인 초대코드 로그인

목적: 코드만 가진 이용자가 추가 정보 입력 없이 로그인하는 화면.

내용: '받은 초대코드로 시작하세요', 코드 입력 필드, '로그인' 버튼. '운영자가 발급한 개인 코드를 입력해주세요'라는 도움말. 코드 없음·유효하지 않음·회수된 코드·로그인 성공 상태를 디자인한다. 코드 입력 이후 이메일 인증 화면을 필수로 이어 붙이지 않는다.

## M06 DataGSM 인증 진행·앱 복귀

목적: 외부 브라우저 인증과 앱으로 돌아오는 중간 상태를 안내한다.

내용: 'DataGSM에서 로그인을 완료해주세요', '브라우저 다시 열기', '다른 방법으로 로그인' 버튼. 앱 복귀 시 '로그인을 확인하고 있어요' 상태와 성공 화면을 만든다. 사용자 취소·인증 실패·제공자 연결 지연 상태를 포함한다. DataGSM의 실제 로그인 페이지는 외부 서비스 화면으로만 표시한다.

## M07 첫 사용 설정·권한 안내

목적: 백그라운드 자동 관리에 필요한 설정을 이해하고 완료하도록 돕는다.

내용: 로그인 완료 → 필요한 권한 확인 → 학교 설정 받기 → 자동 관리 시작의 진행 상태. 와이파이 확인에 필요한 권한, 실행 알림, 필요한 경우 위치 관련 설정을 쉬운 말로 설명한다. '권한 확인하기', '학교 설정 받기', '자동 관리 시작' 버튼을 단계에 맞게 제공한다. 권한 거절·시스템 설정으로 이동·설정 다운로드 실패 상태를 포함한다.

운영체제 권한 창은 OS가 제공하는 화면으로 구분해 표현하고, 앱이 자체적으로 권한을 허용한 것처럼 디자인하지 않는다.

## M08 연결 홈·자동 관리

목적: 현재 연결과 자동 관리 상태를 한눈에 확인하는 메인 화면.

내용: 상단의 자동 관리 상태, 가장 중요한 '자동 관리 켜기/일시 중지' 버튼, 현재 와이파이의 캐릭터·별명·실제 네트워크 이름, 신호 상태, 마지막 학교 설정 동기화 시각. '알아서 연결을 살피고 있어요' 같은 짧은 설명을 사용한다. 최근 발견한 캐릭터로 도감에 들어가는 작은 진입점을 넣는다.

변형: 자동 관리 꺼짐, 정상 관리 중, 학교 와이파이 없음, 연결 확인 중, 연결 실패 후 복구 중, 권한 확인 필요, 저장된 설정으로 이용 중. 현재 와이파이가 정상인데 서버에만 연결되지 않는 상태를 전체 연결 실패로 표시하지 않는다.

## M09 주변 학교 와이파이·상세 패널

목적: 앱이 어떤 후보를 보고 있는지 궁금할 때 확인하는 보조 화면.

내용: 현재 기기 주변에서 보이는 등록된 학교 와이파이 목록. 별명·SSID·신호·최근 관찰 시각·현재 연결 여부를 표시하고, 추천 이유를 한 줄로 보여준다. 항목을 누르면 최근 연결 결과를 확인한다. 지도·설치 장소·비밀번호는 표시하지 않는다.

검색 중·발견 없음·오래된 검색 결과 상태를 포함한다. 평소 사용 흐름에서 이 화면을 열어 수동 선택해야만 자동 관리가 작동하는 구조로 만들지 않는다. Android에서 필요한 수동 조치는 '시스템 Wi-Fi 설정 열기'로 표현한다.

## M10 연결 기록

목적: 자동 관리가 한 일을 나중에 확인하는 화면.

내용: 날짜별로 연결 성공·변경 시도·실패·복구·설정 동기화 기록을 정리한다. 캐릭터 또는 별명, 발생 시각, 간단한 결과를 표시한다. 상세를 누르면 '신호가 약해 다른 후보를 확인했어요'처럼 이해하기 쉬운 설명을 보여준다. 기록 없음 상태도 만든다. 학생의 실시간 이동 경로를 지도에 표시하지 않는다.

## M11 와이파이 도감 전체

목적: 게임처럼 캐릭터를 발견하고 모으는 즐거움을 주는 핵심 화면.

내용: 큰 캐릭터 카드 그리드, '2 / 4 발견' 같은 진행도, 전체·발견·미발견 필터. 미발견은 회색 캐릭터 실루엣, 물음표, 가려진 이름을 사용한다. 발견한 캐릭터는 컬러 그림과 재미있는 별명, 짧은 소개를 보여준다. 카드 그림은 도감 번호나 기술 정보보다 시각적으로 크게 배치한다.

첫 발견 전·일부 발견·전체 수집 완료 상태를 포함한다. 수집 진행을 위해 사용자가 연결을 계속 바꾸도록 유도하지 않는다.

## M12 발견한 캐릭터 상세

목적: 각 와이파이 캐릭터의 개성과 이야기를 즐기는 화면.

내용: 큰 컬러 그림과 재미있는 별명·수집 상태가 중심이다. 짧은 설정과 처음 만난 기록은 보조로 두고 실제 확인된 기록만 표시한다. 지도·장소 설명·설치 위치·SSID·신호·AP 정보는 도감에 넣지 않는다.

캐릭터 예시:
- 쉿파이: 민트색 책 뒤에 숨은 작은 유령. '도서관의 정적을 먹고 자란다. 큰 소리가 나면 신호부터 숨긴다.'
- 밥도둑 핑핑이: 포크와 Wi-Fi 안테나가 달린 주먹밥. '밥 한 숟갈에 패킷 하나. 점심시간이면 누구보다 빠르게 나타난다.'
- 밤샘 패킷몬: 다크서클이 있는 보라색 코딩 슬라임. '버그를 보면 한숨부터 쉬지만, 결국 끝까지 함께한다.'
- 이불 밖은 버퍼링: 파란 이불을 뒤집어쓴 전파 요정. '자기 전 마지막 영상 한 편을 지켜준다. 이불 밖으로 나오는 일은 싫어한다.'

## M13 미발견 캐릭터 상세

목적: 아직 모으지 못한 캐릭터에 호기심을 갖게 하는 상태.

내용: 회색 실루엣, 가려진 이름, '아직 만나지 못한 친구'라는 문구. 회색 화면에서도 캐릭터 외곽 형태가 살아 있어야 한다. 지도·장소 힌트·기술 정보·추가 GPS 권한·강제 이동 퀘스트는 넣지 않는다.

## M14 새 친구 발견·도감 해금

목적: 자동 관리 중 새 캐릭터를 만났을 때 기분 좋은 보상을 전달한다.

내용: 평소에는 작업을 방해하지 않는 작은 발견 알림을 보여주고, 사용자가 열면 회색 실루엣이 컬러로 바뀌는 해금 화면으로 이어진다. 캐릭터 이름, '새 친구를 발견했어요', 갱신된 도감 진행도, '친구 자세히 보기', '계속하기' 버튼을 넣는다.

앱을 보고 있을 때의 축하 화면과 앱 밖에 있을 때의 간단한 알림을 구분해 만든다. 해금은 실제 연결 성공을 확인했을 때 발생한다. 주변 검색으로 신호가 보이거나 연결을 시도했다는 이유만으로 해금하지 않는다. 순위·보상 화폐·아이템 상점은 추가하지 않는다.

## M15 내 계정

목적: 현재 누구의 계정으로 이용 중인지 확인하는 화면.

내용: 프로필 이미지 대신 기본 아바타, 표시 이름, 로그인 방식, 기기 정보, 로그아웃. DataGSM 계정은 제공받은 이름·학년·반·번호를 사용할 경우에만 표시한다. 학교 이메일 계정이나 코드 계정에 없는 학교 정보를 임의로 채우지 않는다. 코드 계정은 '개인 초대코드로 이용 중'과 관리자가 부여한 별칭을 사용할 수 있다.

같은 사람이어도 로그인 방식이 다르면 계정과 도감이 따로 생길 수 있다. 2026-10-31 결정으로 이 화면에 '로그인 수단' 영역을 둔다. 연결된 수단 목록, 수단 추가(그 자리에서 새로 인증), 해제(마지막 수단은 불가)를 제공한다. 추가하려는 수단이 이미 다른 계정에 있으면 두 계정의 도감을 합친다는 확인 화면을 보여주고, 사용자가 확인할 때만 합친다. 이름·이메일이 같다는 이유로 합치기를 먼저 권하지 않는다.

## M16 설정·문제 해결

목적: 자동 관리 동작과 알림을 확인하고 필요한 설정을 복구하는 화면.

내용: 자동 관리 상태, 실행 알림 관련 안내, 학교 설정 마지막 동기화와 수동 새로고침, 권한 상태, 앱 버전, 도움말. '권한 다시 확인', '시스템 설정 열기', '설정 다시 받기' 등 상태에 맞는 버튼을 제공한다. 학교 와이파이 비밀번호 입력이나 내부 점수 계산 가중치를 일반 사용자에게 요구하지 않는다.

오프라인, 권한 거절, 세션 만료, 학교 설정 없음, 회수된 계정의 안내를 변형으로 포함한다. 자동 관리를 끌 때 현재 와이파이 연결 자체가 반드시 끊기는 것처럼 안내하지 않는다.

## M17 Android 실행 알림

목적: 앱 화면 밖에서 자동 관리가 실행 중임을 알려주는 보조 디자인.

내용: OS 알림 영역의 와글 알림 예시. '학교 와이파이 자동 관리 중', 현재 연결 별명 또는 '주변 학교 와이파이를 기다리는 중', 앱 열기·일시 중지 진입점을 담는다. Android 기본 알림 구조에 맞춰 보여준다. 일반 잠금화면에 이메일·개인 초대코드·와이파이 비밀번호를 노출하지 않는다.

## W01 Windows 로그인·초기 설정

세 로그인 방식과 필요한 시스템 설정 안내를 데스크톱 창에 맞게 구성한다. DataGSM은 기본 브라우저를 열고 돌아오는 흐름을 보여준다. 모바일 M02~M07의 내용을 재사용한다.

## W02 연결 홈

왼쪽에는 연결·도감·기록·설정 메뉴, 중앙에는 현재 연결과 자동 관리 버튼, 보조 영역에는 최근 연결 결과와 필요한 조치를 보여준다. 자동 관리 상태를 창 상단에서도 확인할 수 있게 한다. 정상·꺼짐·권한 필요·재연결·학교 밖 상태를 만든다.

주변 학교 와이파이 목록으로 들어가는 진입점을 홈에 두고, 목록·상세는 보조 패널 또는 별도 변형 프레임으로 만든다. M09와 동일하게 별명·SSID·신호·최근 관찰 시각·현재 연결·추천 이유를 보여준다. 검색 중·발견 없음·오래된 검색 결과 상태를 포함한다. Windows에서 수동 연결을 제공한다면 처리 중·실패·복구 상태도 함께 표현한다.

## W03 Windows 도감·캐릭터 상세

넓은 화면에서 캐릭터 카드가 4열 정도로 보이게 구성한다. 컬러 발견 카드와 회색 실루엣 카드를 함께 보여주고, 상세는 옆 패널이나 중앙 모달로 연다. 진행도와 발견 필터를 유지한다. 모바일과 동일한 캐릭터 그림·별명·설정을 사용한다.

## W04 연결 기록

날짜별 연결 성공·변경 시도·실패·복구·설정 동기화 이력을 넓은 목록으로 구성한다. 기록을 선택하면 상세 설명을 옆 패널에 보여준다. 기록 없음과 불러오기 실패 상태를 포함한다.

## W05 설정·내 계정

설정은 구분이 명확한 폼과 상태 영역으로 구성한다. 자동 관리, 권한, 설정 동기화, 앱 정보와 계정 진입점을 제공한다. Windows 위치 접근 등 시스템 권한이 필요한 경우 바로 이동할 수 있는 안내를 넣는다. 내 계정은 M15를 데스크톱 상세 패널로 재배치하고, 설정 동기화 오류와 로그아웃 확인 상태를 포함한다.

## W06 트레이 팝업·메뉴

작은 팝업에 현재 연결 별명, 자동 관리 상태, 앱 열기, 일시 중지/다시 시작, 완전 종료를 제공한다. '자동 관리 중', '학교 와이파이 기다리는 중', '확인 필요' 상태를 구분한다. 프로그램 창을 닫을 때 처음 한 번 '트레이에서 계속 관리해요'라는 안내를 제안한다.

## A01 관리자 로그인·접근 제한

목적: 지정된 운영자가 관리자 웹에 진입하는 화면.

내용: 와글 로고, '운영자 로그인', 관리자 계정으로 인증하는 버튼. DataGSM 인증을 이용하는 구성을 디자인용 기본안으로 제안한다. 실제 관리자로 사전 지정된 계정 한 개만 접근한다. 일반 계정으로 접근했을 때는 '관리자 권한이 없는 계정이에요'와 계정 변경·돌아가기 버튼을 보여준다. 관리자 공개 회원가입이나 역할 선택은 제공하지 않는다.

## A02 관리자 대시보드

목적: 관리가 필요한 항목을 빠르게 찾는 시작 화면.

내용: 등록 네트워크 수, 등록 AP 수, 위치 미등록 AP 수, 등록 사용자 수, 유효한 개인 코드 수. 위치 미등록 AP와 설정이 아직 연결되지 않은 도감 항목 등 실제 관리 작업으로 연결되는 목록을 배치한다. 네트워크 추가, 위치 등록, 개인 코드 발급을 바로 할 수 있게 한다. 현재 수집하지 않는 실시간 접속자 수나 전교생 위치를 표시하지 않는다.

## A03 네트워크 목록

목적: 학교 와이파이 접속정보를 중앙 관리하는 화면.

내용: 표시 이름, 실제 SSID, 보안 방식, 연결된 AP 수, 사용 여부, 설정 변경 시각. 검색과 사용 여부 필터, 네트워크 추가, 상세·수정 진입점을 제공한다. 비밀번호는 목록에서 마스킹한다. 데이터 없음·검색 결과 없음·읽기 오류 상태를 만든다.

네트워크 한 개와 설치 AP 여러 개의 관계가 이해되도록 표현한다. 같은 비밀번호를 AP마다 반복 입력하는 폼으로 만들지 않는다.

## A04 네트워크 등록·수정

목적: 네트워크 이름과 정확한 접속정보를 입력하고 배포 대상 설정을 저장한다.

내용: 표시 이름, SSID, 지원 보안 방식, 비밀번호, 사용 여부, 설명. 비밀번호 입력 확인 토글과 저장·취소 버튼을 제공한다. 저장 성공과 입력 오류를 보여준다. 앱이 변경된 설정을 다음 동기화 때 받는다는 안내를 넣고, 모든 기기가 즉시 새 비밀번호로 바뀌었다는 성공 문구는 사용하지 않는다. 실제 학교 비밀번호 대신 마스킹된 예시를 사용한다.

## A05 전체 AP 위치 지도·목록

목적: 관리자가 학교에 등록된 모든 와이파이 장치의 설치 위치를 보는 핵심 화면.

내용: 큰 학교 배치도 또는 층별 도면과 AP 표시, 옆의 전체 AP 목록. 건물·층·위치 등록 여부 필터, 현재 선택된 AP의 상세 패널을 제공한다. 목록이나 지도에서 AP를 선택하면 두 영역이 함께 강조된다.

각 AP의 관리용 이름, 연결된 네트워크, 건물, 층, 구체적인 설치 장소를 확인할 수 있어야 한다. 위치 미등록 AP도 목록에서 확인하고 등록할 수 있어야 한다. 현재 운영자 기기 주변에서 검색되는 AP만 보여주는 화면으로 만들지 않는다.

학교의 실제 도면이 없으므로 예시 배치도에는 '예시 배치도'라고 표시한다. 지도에 학생의 현재 위치를 표시하지 않는다. 설치 위치 정보가 있다고 실시간 온라인 상태까지 확인된 것처럼 표시하지 않는다.

## A06 AP 등록·위치 수정

목적: 설치 장치별 식별 정보와 위치를 등록하는 화면 또는 상세 편집 패널.

내용: 관리용 이름, 연결할 네트워크 선택, BSSID, 건물, 층, 설치 장소 설명, 도면 위 표시 위치. '본관 / 2층 / 도서관 입구 천장'처럼 구체적인 예시를 사용한다. 위치 미등록·등록 완료·중복 식별 정보·저장 오류 상태를 만든다. 동일 네트워크의 여러 AP를 각각 위치 등록할 수 있어야 한다.

## A07 도감 캐릭터 목록

목적: 와이파이에 붙일 별명과 캐릭터 콘텐츠를 관리하는 화면.

내용: 컬러 그림 썸네일, 도감 번호, 별명, 연결된 네트워크/AP 항목, 사용 여부. 검색, 캐릭터 추가, 편집 진입점을 제공한다. 학생의 미발견 상태와 관계없이 관리자는 전체 캐릭터를 볼 수 있다. 학생별 발견 여부를 이 콘텐츠 목록의 공개 여부와 혼동하지 않는다.

## A08 도감 캐릭터 등록·편집

목적: 각 와이파이를 재미있는 수집 대상으로 꾸미는 화면.

내용: 도감 번호, 별명, 컬러 캐릭터 이미지, 한 줄 소개, 짧은 이야기, 연결할 와이파이 항목. 설치 위치는 관리자 AP 화면에서 관리하고 학생 도감에는 공개하지 않는다. 오른쪽에 학생이 보는 '미발견 회색 실루엣'과 '발견 컬러 카드' 미리보기를 함께 배치한다. 긴 이름, 이미지 미등록, 내용 저장 완료 상태를 포함한다.

콘텐츠 편집과 실제 연결 성공에 따른 해금 동작을 구분한다. 임의의 점수·희귀도·금액 설정을 추가하지 않는다.

## A09 사용자 목록·상세

목적: 서비스 이용자와 접근 상태를 관리한다.

내용: 표시 이름 또는 개인 코드 별칭, 로그인 방식(DataGSM/이메일/개인 코드), 제공받은 경우의 학년·반·번호, 가입일, 서비스 접근 상태. 사용자 상세에는 로그인한 기기의 플랫폼, 마지막 로그인 시각, 세션 상태를 보여준다. 개인 코드 계정에는 없는 이메일이나 학번을 임의로 채우지 않는다.

서비스 접근 제한·세션 종료 시 확인 모달을 제공한다. 문구는 앱 서비스 접근과 정보 갱신 제한을 설명해야 한다. 이미 기기에 저장된 학교 와이파이 접속 자체가 즉시 차단됐다고 표현하지 않는다.

## A10 개인 초대코드 목록

목적: 개인에게 발급한 코드의 상태를 관리한다.

내용: 발급 대상 별칭, 코드 식별용 일부 문자, 유효/회수 상태, 발급일, 연결된 사용자. 코드 발급, 회수, 재발급 진입점을 제공한다. 전체 코드는 발급 이후 계속 노출하지 않는다. 같은 개인 코드가 본인의 휴대폰·노트북에서 쓰일 수 있다는 설명을 포함한다.

## A11 개인 코드 발급·회수·재발급

목적: 코드 발급과 한 번만 보여주는 전달 화면을 디자인한다.

내용: 발급 대상 별칭 입력 → 발급 완료 → 생성된 코드와 복사 버튼. '이 코드는 지금만 전체를 확인할 수 있어요'라는 안내와 완료 버튼을 넣는다. 회수와 재발급에는 대상이 누구인지 명확한 확인 모달을 제공한다. 예시 코드는 데모용임을 표시한다. 별도 이메일 입력은 필수로 요구하지 않는다.
