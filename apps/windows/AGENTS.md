# Windows 작업

루트 AGENTS.md와 이 영역 README.md를 따른다. C#으로 구현한다. Native Wi-Fi 호출과 판단 엔진을 분리하고 요청 접수와 실제 연결 성공을 구분한다. 권한·드라이버·위치 동의 차이와 트레이 종료·재실행을 검증한다. 중지 시 기기의 기존 Wi-Fi를 임의로 해제하지 않는다. 토큰·접속정보는 OS 보안 저장소를 사용한다. 프로젝트를 만들면 실제 빌드·단위 테스트를 CI에 연결한다.

현재 .NET 10·WPF의 개인 코드 인증·자동 관리·그림 도감·트레이 앱이 있다. Core의 직렬 갱신·중지 선행 취소·실패 구분과 CurrentUser 보호·암호문 원자 교체를 유지한다. 코드·토큰은 로그·명령행·스크린샷에 넣지 않는다. 기본 localhost 주소는 개발용이며 실제 배포 주소처럼 표시하지 않는다. 실행 중인 앱을 종료한 뒤 npm run windows:check를 실행한다. 인증 성공은 Wi-Fi 연결이 아니며 합성 관찰은 실제 학교 연결 증거가 아니다.
